처음에는 localStorage에 count 키가 없다. 아래 페이지에서 버튼을 두 번 클릭한 직후의 「count 변수 / 화면의 숫자 / getItem("count")의 반환값」을 순서대로 고른 것은? 따옴표가 있는 값은 문자열이다.

HTML + JavaScript

<p id="result"></p>
<script>
  let count = Number(localStorage.getItem("count") ?? 0);
  const result = document.querySelector("#result");
  result.textContent = count;

  document.querySelector("#add").addEventListener("click", () => {
    count += 1;
    localStorage.setItem("count", count);
    result.textContent = count;
  });
</script>

출제 토픽 · 변수·DOM·이벤트·localStorage의 연계

출제 토픽 · CSS 단위 px·em·rem

font-size에 사용한 em은 상속받을 글꼴 크기를 기준으로 계산한다. 따라서 20 × 1.5 = 30px이다.

padding의 em은 해당 요소 자신의 계산된 font-size를 기준으로 하므로 30px이다.

rem은 루트 요소의 font-size를 기준으로 하므로 width는 16 × 10 = 160px이다. px는 CSS 픽셀 단위이며 기기 픽셀과 항상 1:1인 것은 아니다.

기억할 점 font-size의 em 기준과 padding의 em 기준을 혼동하지 않는다.

출제 토픽 · Box Model과 box-sizing

content-box의 width는 콘텐츠 영역의 너비이다. .a는 200 + 20×2 + 5×2 = 250px이다.

border-box의 width는 padding과 border를 포함한다. .b는 200px이며 콘텐츠 영역은 150px이다.

margin은 border-box에도 포함되지 않는다. 문제에서는 margin을 제외하도록 명시했다.

기억할 점 content-box는 바깥으로 더하고, border-box는 지정 너비 안에 padding·border를 포함한다.

출제 토픽 · CSS 우선순위에 따른 Flexbox 방향 결정

#layout의 ID 선택자가 .panel 및 .page .panel보다 명시도가 높으므로 flex-direction은 column이다.

display: flex는 .panel 규칙에서 그대로 적용된다. 이 시험의 가로쓰기 조건에서 column은 위에서 아래 방향이므로 A가 위에, B가 아래에 놓인다.

기억할 점 속성마다 승리하는 선언을 따로 찾고, 결정된 방향에 따라 주축을 판단한다.

31저장소난도 중

일반 브라우징 환경에서 두 저장소에 값을 저장했다. 같은 탭의 새로고침, 그리고 해당 탭의 페이지 세션을 끝낸 뒤 독립된 새 탭에서 같은 출처를 여는 상황을 올바르게 설명한 것은? 세션 복원·시크릿 모드·사용자 데이터 삭제·저장소 차단은 고려하지 않는다.

출제 토픽 · localStorage와 sessionStorage의 수명

localStorage는 출처별 저장소로 브라우저 세션을 넘어 유지될 수 있다. 다만 명시적 삭제나 브라우저 정책 등에 따라 삭제될 수 있으므로 영구 보장이라고 표현하면 안 된다.

sessionStorage는 출처뿐 아니라 탭의 페이지 세션을 기준으로 분리된다. 같은 페이지 세션에서 새로고침할 때는 유지되지만, 문제처럼 세션을 끝내고 독립된 새 탭을 열면 이전 값이 공유되지 않는다.

기억할 점 sessionStorage도 새로고침에는 유지된다. 새로고침과 페이지 세션 종료를 구분한다.

32HTML난도 상

입력 상태를 바꾸지 않고 아래 제출 버튼을 직접 클릭했다. 실제 제출 데이터에 포함되는 이름·값의 집합을 모두 올바르게 나열한 것은? 유효성 검사나 제출을 막는 다른 코드는 없다.

  <input type="checkbox" name="skill" value="js">
  <input type="radio" name="region" value="seoul" checked>

</form>

출제 토픽 · Form 제출 시 포함되는 입력 데이터

name이 없는 nickname과 disabled인 code는 제외된다. readonly인 grade는 제출에 포함된다.

체크박스·라디오에서는 선택된 skill=java와 region=seoul만 포함된다.

hidden 입력과 CSS로 숨긴 memo는 숨겨져 있다는 이유로 제외되지 않는다. 실제 클릭한 제출 버튼도 name과 value가 있으므로 action=save가 포함된다.

기억할 점 name·disabled·선택 상태·실제 제출 버튼을 확인한다. 화면에 보이는지는 별개의 기준이다.
